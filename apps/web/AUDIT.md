# WarpTalk web UI audit

Scope: `apps/web` (Vite/React) against the legacy Next.js app (`warptalk-web`: `DESIGN.md`, `src/app/globals.css`, `src/components/**`, `messages/en/*`) and the app's own `DESIGN_SYSTEM.md`.
Method: Playwright/Chromium, real backend, dark and light, 1440x900 / 1280x800 / 390x844, seeded data (2 workspaces, 34 rooms in every status incl. a 150-char title, a 3-person lobby with a very long name, a plain joiner). Screenshots are in `apps/web/audit/<area>-<state>-<theme>-<w>.png` (about 300 files). A scripted pass at 1280 ran last and covers the same states as 1440; findings cite 1440 or 390 files. Nothing under `src/` or `e2e/` was edited.
Caveats: the dev API on :18080 was restarted several times by other agents during the run, so a private API copy on :18081 and Vite on :5198 were used. The session in `src/` was moving (another agent editing), so file:line references can drift. Not covered: the LiveKit connected state (backend has no LiveKit, so the joined meeting stage with live captions was never rendered; MT findings about it come from code), and legacy pages were compared by code/tokens, not rendered.

Paths below are relative to `apps/web/audit/` for screenshots and to `apps/web/src/` for new-app code. Legacy paths are relative to `warptalk-web/`.

What passes (verified, do not touch): the surface ladder and hairlines (`--canvas #050506`, `--panel #0a0b0c`, `--surface-1..4`, `--hairline #232428`, `--hairline-strong #313338`) match legacy `globals.css` hex-for-hex in both themes; 8px control radius, 12px cards, 16px dialogs; focus ring only on `:focus-visible`; skip link; global reduced-motion rule; status pills have dot plus text; body/headline text contrast is 5.0:1 or better on every surface (ink-subtle on surface-4 is the lowest at 5.04:1).

## Top 10

1. **IA-01 (P0)** The product has no Home, History, Calendar, Members, Documents, Glossary, Knowledge, Voice profiles or Assistant. The sidebar is 5 flat links and `/` just redirects to `/rooms`.
2. **LY-01 (P0)** Room detail at 390px overflows the page (scrollWidth 608-643px). Listens and Status columns are off-screen, with a blank band to the right of the viewport.
3. **MT-01 (P0)** The meeting pre-join is a name field plus a permanently visible, disabled control bar, with no device or mic check and no language choice. It sits above a participant grid and captions panel in a layout with large dead space.
4. **FN-02 (P0)** The default workspace is "first in the list" and is never persisted until the user switches. A user with two workspaces lands in an empty one and sees "No rooms yet" while another workspace has 34 rooms.
5. **DS-01 (P1)** Brand is an invented "W" tile. The legacy logo assets (`public/assets/logos/warptalk-sidebar-logo.png`, `-icon.png`) are never used, including the favicon.
6. **FN-09 (P1)** Filtering rooms to a status with no results shows "No rooms yet - Create a room, share the code...". This is the wrong empty state and invites duplicate creation.
7. **FN-01 (P1)** The command menu advertises `G R` and `C` shortcuts that are not implemented (only Ctrl/Cmd+K is bound).
8. **DS-02/DS-03 (P1)** Icon set and sidebar metrics differ from legacy: lucide stroke vs Phosphor duotone 16px; row `h-8`/14px vs `h-[30px]`/13px; no grouped nav.
9. **MT-02/MT-03 (P1)** The meeting control bar has only mic, listen and leave. Legacy has camera, share, hand, reactions, captions toggle, host controls, recording and settings. The captions panel has no transcript/chat/people tabs and no speaker colours.
10. **A11Y-08 (P1)** The mobile navigation drawer is a bare div: no dialog role, no focus trap, no Escape. Keyboard focus walks behind the overlay.

## Findings

Severity: P0 = blocks core use or makes the product look unfinished at first glance; P1 = visibly wrong or clearly off-spec; P2 = polish.
