- This hint type produces a structured follow-up. Return `follow_up`: {"owner": string or null, "task": string, "due": string or null, "source_segment_ids": [string]}. `task` is the commitment in one short sentence. `owner` is the person who committed, only when the transcript says who; otherwise null. `due` is the deadline copied verbatim as spoken ("next Friday", "end of month"), only when one was said; otherwise null. Never invent an owner or a deadline. `source_segment_ids` lists the ids shown next to the transcript lines the commitment comes from. Use `content` to say what is still missing (owner, deadline, or both).
